# Garden House — redesign

Redesign of [techs-gardenhouse.com](https://www.techs-gardenhouse.com/) for the garden house, using the original site's content, photos and 3D model.

| Base | `main` | https://sl-ee-p.github.io/garden-house-web/main/ |

The site is plain HTML, CSS and JavaScript with no build step: open `index.html` or serve the folder.
`.github/workflows/pages.yml` republishes every version on each push to `main` or a `design/*` branch.

Analysis of the original site: [`docs/analysis.md`](docs/analysis.md). Developer tools: [`tools/README.md`](tools/README.md).
